# Управление VPN через быстрые команды (iOS без платного аккаунта)

Приложение не поднимает туннель само (нужен Network Extension), а управляет VPN стороннего клиента.

## Один раз
1. Установите VLESS-клиент: Happ, v2RayTun, Streisand или Hiddify.
2. В KitConn нажмите на ручку: ссылка на сервер откроется в клиенте. Импортируйте её и один раз подключитесь в клиенте,
   чтобы iOS создала VPN-конфигурацию (Настройки → VPN).
3. Откройте приложение **«Быстрые команды»** и создайте две команды с точными именами:
   - **KitConn On** — действие «Установить VPN» → «Подключить» → выберите конфигурацию клиента;
   - **KitConn Off** — действие «Установить VPN» → «Отключить» → та же конфигурация.

## Дальше
Ручка в KitConn запускает эти команды (откроется «Команды» на секунду и вернёт в приложение).
Статус и таймер берутся из системы по факту активного VPN, а не из предположений приложения.

## Ограничения
- Для каждого нового сервера первый тап снова передаёт ссылку клиенту.
- Скорость и трафик не показываются: данные туннеля чужого приложения недоступны.
- Определение VPN основано на системном признаке туннельного интерфейса и может отличаться между версиями iOS.
